# Muse Agent Skill — 开发计划（最终）

## Context

Muse ↔ coding agents（Claude Code / Zcode）双向通信：Skill + Mac 本地 MCP server，SSH 调云主机上的 musegadget 常驻服务。一次性 BLE 配对延后（用户回家用 Windows 台式机 WSL2 + USB 蓝牙适配器尝试），配对/授权文档**独立成篇**。

## 交付物

1. `pyproject.toml`（uv 项目，`[project.scripts] muse-agent`，依赖 `mcp`）+ README + .gitignore
2. `src/muse_agent/`：config.py / ssh.py / adapter.py / server.py（FastMCP stdio，工具：muse_status、muse_send、muse_wait、muse_chat、muse_sessions）
3. `scripts/provision.sh`（SSH 自动在云主机装 SDK+服务）、`scripts/import_state.sh`（配对产物导入云主机）
4. `skills/muse/SKILL.md`
5. **独立授权文档** `docs/pairing.md`：重点写 Windows WSL2 + usbipd-win + USB BLE 配对全流程（sdk token 申请 → WSL 装 BlueZ → install.sh → 手机 app 配对 → 导出 state → 拷到云主机 → import_state），并附 token/安全注意事项（token 不进 git、断连后命令继续运行的警告）
6. `docs/claude-code.md`、`docs/zcode.md`（MCP 注册配置）
7. `tests/`：mock ssh 的 adapter 单测 + server 工具注册测试

## 验证

- `uv run pytest` 全绿
- `uv run muse-agent` stdio 手动调用 `muse_status`，配对前返回清晰"未配对"提示
- `scripts/provision.sh --dry-run` 输出将在云主机执行的命令清单

配对完成后的端到端验证（`muse_chat("hello")`）留待用户提供配对 state。
